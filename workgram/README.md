# Папка workgram

Здесь файлы WorkGram и скрипт apply.py. Сборка (workgram-win.yml) сама копирует их в исходники AyuGramDesktop
и вносит небольшие правки: подключает библиотеку в CMakeLists.txt, добавляет клавишу F9 в mainwindow.cpp
и запуск проверки ключа и моста к Telegram в core/application.cpp.

- src: интерфейс, проверка ключа, настройки (не зависят от внутренностей Telegram)
- tg: адаптер к клиенту Telegram (список коллекций, опрос маркета, чат с черновиком)

Загрузи эту папку целиком в корень своего форка (ветка dev), рядом с папкой Telegram.
Файл workgram.log рядом с приложением показывает шаги: проверку ключа, причины сбоя связи, ответы Telegram по владельцам.
