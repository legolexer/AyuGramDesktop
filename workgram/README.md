# Папка workgram

Здесь лежат файлы WorkGram и скрипт apply.py. Сборка (workgram-win.yml) сама копирует их в исходники AyuGramDesktop
и вносит небольшие правки: подключает библиотеку в CMakeLists.txt, добавляет клавишу F9 в mainwindow.cpp
и проверку ключа в начале запуска (core/application.cpp).

Загрузи эту папку целиком в корень своего форка (ветка dev), рядом с папкой Telegram.
Что делает этот этап:
1. При запуске приложение просит ключ (сервер keyhistory.duckdns.org). Без действующего ключа оно не стартует.
2. F9 открывает окно настроек WorkGram (пока на тестовых данных).
